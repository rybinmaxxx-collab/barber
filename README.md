# Барбер от Бога — сайт барбершопа

Одностраничный сайт барбершопа «Барбер от Бога» (Москва, ул. Тарусская, 14к1).
Собран по техническому заданию «Барбершоп „Барбер от Бога“, версия 1.0»
(12 блоков: Preloader + 11 секций, тексты 1:1 из ТЗ).

**Позиционирование:** «Считаем не филиалы, а годы». Платформа бренда — факты,
конкуренты Ясенево, дистанцирование, тон голоса — в [`BRAND.md`](BRAND.md).

## Стек

| Слой | Чем сделано |
|---|---|
| Каркас | Next.js 14 (App Router) + TypeScript |
| Стили | CSS из ТЗ в `app/globals.css` (BEM) + Tailwind для утилит |
| Движение | GSAP 3 + ScrollTrigger + SplitText + DrawSVG |
| Скролл | Lenis, синхронизированный с тикером GSAP |
| 3D | React Three Fiber + Drei (процедурное кресло, без внешних ассетов) |
| Хостинг | Vercel или GitHub Pages — сборка статическая (`output: 'export'`) |

Шрифты (Oswald + Manrope, только кириллица и латиница, OFL) **самохостятся**
в `public/fonts`: ноль сторонних доменов, сайт не ломается, если CDN недоступен.

## Отличия от буквы ТЗ (и почему)

1. **Barba.js не используется.** Barba сам подменяет контейнер, перехватывая
   клики по ссылкам; на App Router этим занимается роутер Next.js, и две системы
   дерутся за один DOM. Переход «Парикмахерская» (clip-path, 600–800 ms,
   `power3.inOut`) сделан на GSAP в `components/PageTransition.tsx` — для зрителя
   результат тот же.
2. **3D-кресло собрано процедурно**, а не загружено как `.glb` со Sketchfab:
   лицензии на чужие модели, вес файла и правило «ноль сторонних запросов».
   Поведение объекта — как в разделе 15.2 ТЗ.
3. **Горизонтальная лента работ** двигается на реальную ширину ленты, а не на
   `xPercent: -100 * (items - 1)`: карточки шириной 350 px, и формула из ТЗ
   увела бы половину работ за край экрана.
4. **Фотографий пока нет** — в `public/images` лежат SVG-заглушки под размеры
   макета. Заменить на реальные снимки: шесть работ, «отец и сын», портрет Надира.

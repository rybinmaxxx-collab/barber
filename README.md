# Барбер от Бога — сайт барбершопа

Одностраничный сайт для барбершопа «Барбер от Бога» (Москва, ул. Тарусская, 14к1).
Собран по регламенту из [`PIPELINE.md`](PIPELINE.md).

**Позиционирование:** «Считаем не филиалы, а годы». Полная платформа бренда —
факты, разбор конкурентов Ясенево, дистанцирование, тон голоса и мотив текстов —
в [`BRAND.md`](BRAND.md). Всё, что написано на сайте, выводится оттуда.

**Стек:** статика — HTML + CSS + ES-модули. Сборки нет.
Three.js, GSAP/ScrollTrigger, Lenis и шрифты **самохостятся** (`assets/vendor/`,
`assets/fonts/`): ноль сторонних доменов, сайт не ломается, если CDN недоступен —
для российской аудитории это не паранойя, а нормальная предосторожность.

### 3D-сцена

Один объект на всю страницу — **опасная бритва**, и весь вертикальный скролл это её таймлайн:

```
герой ..  #count    сложена, медленно поворачивается
#count .. #craft    раскрывается: клинок выходит из рукояти
#price .. #works    разлетается на части
#works .. #master   части живут отдельно
#master .. #words   собирается обратно и закрывается
```

Границы актов не вбиты числами: `computeAnchors()` в `scene.js` считает их из реальных
позиций секций и пересчитывает на `resize`/`load`. Добавили блок — таймлайн не поехал.
Канвас зафиксирован на весь экран и живёт под контентом всей страницы, а не только
в первом экране.

Вся геометрия процедурная — **ни одного внешнего ассета и ни одного запроса за текстурами**.
Клинок и накладки рукояти строятся из `THREE.Shape` + `ExtrudeGeometry`, шарнир и вставки
латунные. Металлу нужно что-то отражать, поэтому вместо HDR-файла студийный градиент
рисуется в `<canvas>` и вешается как equirect-окружение.

Пока под объектом плотный текст (прайс, вопросы), материалы приглушаются до 34 % —
диапазоны считаются из реальных координат секций и переживают любые правки вёрстки.

Деградация: нет WebGL → градиент вместо сцены; `prefers-reduced-motion` → почти статика;
вкладка неактивна → рендер останавливается; `pixelRatio` ограничен двойкой.

### Движение

Lenis (`lerp 0.09`) как основа, GSAP ScrollTrigger поверх. Реализовано:
шкала глав слева (11 разделов, активный подсвечивается и раскрывает название),
мобильное меню с тем же оглавлением, живой статус «сейчас открыто» по московскому
времени, построчный выезд заголовка из маски, reveal-каскады через IntersectionObserver,
параллакс по `data-speed`, бегущая строка, меняющая направление вместе со скроллом,
горизонтальная лента работ, привязанная к вертикальному скроллу, 3D-tilt карточек
с бликом за курсором, магнитные кнопки, кастомный курсор на `mix-blend-mode: difference`,
анимированные счётчики, полоса прогресса чтения.

### SEO

`@graph` из `HairSalon` + `WebSite` + `FAQPage` + `BreadcrumbList` + `OfferCatalog`,
`aggregateRating` только из реальных данных Яндекс.Карт (5,0 / 86 оценок / 74 отзыва),
`openingHoursSpecification` 10:00–22:00 ежедневно,
FAQ в разметке дословно совпадает с FAQ на странице, `robots.txt` явно разрешает
AI-краулеров (GPTBot, ClaudeBot, PerplexityBot, YandexBot) — это влияет на попадание
в ответы нейропоиска.

## Запуск

```bash
python3 -m http.server 8080
# http://localhost:8080
```

Открывать именно через сервер: `scene.js` — ES-модуль, по `file://` он не загрузится.

## Деплой

`.github/workflows/pages.yml` публикует содержимое репозитория на GitHub Pages
при пуше в `main`. Нужно один раз включить Pages: Settings → Pages → Source: GitHub Actions.

Vercel / Netlify — без настроек: подключить репозиторий, build command пустой,
output directory — корень.

## Как вносить правки

Откройте сайт с `?edit` в адресе — поверх каждой секции появится её код (`B-01` … `B-14`).
Скриншот в этом режиме плюс три строки:

```
[B-06] что:    цена теряется на телефоне
       хочу:   цену в одну строку с названием
       почему: клиенты не долистывают
```

Подробно — в [`PROCESS.md`](PROCESS.md).

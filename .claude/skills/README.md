# Скиллы этого репозитория

Четыре скилла в `.claude/skills/` подхватываются Claude Code автоматически —
ничего устанавливать не нужно. Достаточно открыть проект и попросить
«сделай сайт для …» или «прогони SEO-аудит».

| Скилл | Что делает | Когда срабатывает |
|---|---|---|
| `gated-delivery` | ведёт проект по воротам: бриф → факты → образцы → тексты → каркас → сборка → ревизия → приёмка | «начать проект», «внести правки», «на каком мы этапе» |
| `vibe-site-factory` | оркестратор конвейера: разведка → тексты → дизайн → код → SEO → деплой | «сделай сайт», «лендинг для бизнеса», «сайт с анимациями» |
| `growth-agency` | маркетинговое агентство из 6 ролей: стратег, копирайтер, CRO, перформанс, контент, аналитик | «стратегия», «тексты на лендинг», «поднять конверсию» |
| `super-seo` | техаудит, семантика, on-page, Schema.org, локальное SEO/карты, GEO/AEO | «SEO аудит», «микроразметка», «локальное SEO» |
| `site-cloner` | реверс-инжиниринг живого сайта: токены, шрифты, параметры анимаций, проверка через SSIM | «сделай как на сайте X», «повторить анимации» |

## Как это устроено

Скилл = папка с `SKILL.md`, где во frontmatter есть `name` и `description`.
Claude читает **только описания** всех скиллов (дёшево), и подгружает тело
нужного скилла в момент, когда задача совпала с описанием. Поэтому описание —
это не документация, а условие срабатывания: в нём должны стоять те слова,
которыми пользователь реально формулирует задачу.

```
.claude/skills/
  gated-delivery/SKILL.md      ← процесс: ворота, фиксация решений, правки с адресом
  vibe-site-factory/SKILL.md   ← производство: вызывает остальные три
  growth-agency/SKILL.md
  super-seo/SKILL.md
  site-cloner/SKILL.md
```

`gated-delivery` отвечает за **предсказуемость** (когда и что утверждаем),
`vibe-site-factory` — за **скорость** (как быстро собираем). Они не конкурируют:
первый решает, что второму можно начинать.

Три уровня установки, если понадобится вынести за пределы репозитория:

| Уровень | Путь | Область |
|---|---|---|
| Проект | `.claude/skills/` | только этот репозиторий (сейчас используется) |
| Пользователь | `~/.claude/skills/` | все проекты на машине |
| Плагин | marketplace + `/plugin install` | команда, версионирование |

## Источники и что именно взято

Скиллы написаны заново под русский локальный бизнес, но логика разобрана
по публичным наборам. Ниже — что откуда, чтобы можно было сходить в оригинал
за глубиной.

**Клонирование сайтов**
- [ericshang98/Perfect-Web-Clone](https://github.com/ericshang98/Perfect-Web-Clone) и
  [perfect-web-clone-skill](https://github.com/ericshang98/perfect-web-clone-skill) —
  идея контракта «агент = мозг, инструмент = руки и глаза», измеримые ворота
  качества и ровно два финальных состояния (`ready_for_user_review` /
  `failed_with_residuals`).
- [voidmatcha/ui-clone-skills](https://github.com/voidmatcha/ui-clone-skills) —
  главное заимствование: анимации вытаскиваются из CSS и **JS-бандлов**
  (GSAP / Framer Motion / Lenis / Webflow IX2), а проверка идёт через AE/SSIM,
  vision-модель включается только когда авто-проверка не прошла. Оттуда же —
  единый `transition-spec.json`, чтобы не анализировать сайт дважды.

**Маркетинг**
- [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills) —
  45+ скиллов (CRO, копирайтинг, офферы, лончи) и ключевая архитектурная идея:
  **все скиллы сначала читают общий контекст продукта**. У нас это
  `brand-context.md`.
- [OpenClaudia/openclaudia-skills](https://github.com/OpenClaudia/openclaudia-skills) —
  разбиение маркетинга на атомарные навыки и набор ролей.

**SEO**
- [AgriciDaniel/claude-seo](https://github.com/AgricIDaniel/claude-seo) —
  оркестратор с веерным запуском подпроверок, слой Local & Maps
  (карточка, NAP-консистентность, аналитика отзывов) и слой GEO/AEO —
  оптимизация под цитирование в AI-выдаче. Оттуда же требование: каждая
  рекомендация несёт наблюдение, зависимость и способ себя опровергнуть.

## Почему переписано, а не подключено как есть

1. Оригиналы заточены под англоязычный SaaS: Google-first, hreflang, ICP B2B.
   Локальному бизнесу в РФ нужен Яндекс-first и карточка на картах как канал №1.
2. Часть скиллов требует платных API (Ahrefs, DataForSEO, SemRush) и MCP-серверов —
   без ключей они не работают, а логика в них ценная и переносимая.
3. Набор из 45–380 скиллов раздувает контекст. Здесь четыре, и они покрывают
   один сквозной сценарий целиком.

Если нужен полный арсенал — оригиналы ставятся рядом и не конфликтуют:

```bash
npx skills add coreyhaines31/marketingskills     # маркетинг
npx openclaudia install --all                    # ещё маркетинг
git clone https://github.com/AgricIDaniel/claude-seo ~/.claude/skills/claude-seo
```
